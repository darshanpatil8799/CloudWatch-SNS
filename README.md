## 📌 Project Overview

<<<<<<< HEAD
This project demonstrates how to create a **Linux server on Amazon EC2** and securely connect to it using **PuTTY and SSH** from a Windows machine.

It covers launching an EC2 instance, creating a key pair, configuring Security Groups, converting the AWS `.pem` key into `.ppk` format using PuTTYgen, and connecting to the Linux server through PuTTY. :contentReference[oaicite:1]{index=1}
=======
This project demonstrates how to host a **static website** using **Amazon S3**. It covers creating an S3 bucket, enabling static website hosting, configuring bucket policies, uploading website files, and making the website publicly accessible.
